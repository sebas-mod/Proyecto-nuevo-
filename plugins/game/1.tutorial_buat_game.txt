1. STRUKTUR Archivo
-----------------------------------------------------------
Para crear un nuevo juego ( mishel: Adivina Kuking ), usted necesita 2 archivos:
1. Archivo Datos: \`src/datos/tebakkucing.json\`
2. Archivo Plugin: \`plugins/game/tebakkucing.js\`
Mismo que Yak, su nombre de archivo

-----------------------------------------------------------
2. Archivo Datos (JSON VALIDATION & Formato)
-----------------------------------------------------------
El archivo JSON debe contener Array of Objects. El sistema tiene retroceso y el campo que puede ser autenticado, pero es un predeterminado que espera nuevas estructuras:

Un juego de Texto ( Estándar )
[
  {
    "index": 0,
*El Kusking que no tiene una bala llamada?
"respuesta": "Sphynx♪
  },
  {
    "index": 1,
*La mayor raza de puking del mundo*
 "respuesta": "Maine Coon"
  }
]

B.
[
  {
    "index": 0,
    "img": "https://domain.com/kucing1.jpg",
"respuesta": "Anggora",
*Decryption* *Sway from Turki* *Ucrania/ Opcional, como una soalla/una conformidad agregada*
  }
]

* Validasi Eol JSON: *
- JSON debe ser válida.
- Asegúrese de que el archivo de codificación es UTF @-@ 8.
- Por defecto de campo tenab:\`sello\`(pregunta) y\`respuesta\`Si utiliza otro campo, debe configurarse en configuración (ver la sección ).\`cuestión\`y\`respuestaField\`).
